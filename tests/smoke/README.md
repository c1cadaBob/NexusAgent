# 阶段冒烟脚本

每个阶段提供 `P<阶段号>.sh` 一键脚本，脚本必须输出可读的 `PASS` 或 `FAIL`，并检查该阶段的核心产物、依赖连通性和关键接口。P0/P1/P2/P3/P4/P5 脚本已随阶段任务交付；P6 已交付 P6-01 基础业务闭环门禁、P6-02 防腐层/防绕过/恶意插件隔离门禁和 P6-03 故障注入/降级路线/provider 回滚/plugin rollback 门禁；P7 已交付 P7-01 至 P7-05 高级能力 alpha 增量和阶段门禁报告；P8-01 已交付生产 Compose/Kubernetes 编排静态门禁，P8-02 已交付 CI/CD 发布门禁、GHCR tag candidate publish、provider/plugin 兼容矩阵和上游追踪门禁，P8-03 已交付生产告警、备份恢复 profile、deterministic restore drill 和 secret isolation 门禁。

- `P0.sh`：检查仓库结构、vendor manifest、任务提示词、P0 决策记录和公共契约基线。
- `P1.sh`：检查平台 contracts、Coordinator/Policy-Gate、数据服务、开发 Compose、端口和平台错误码。
- `P2.sh`：检查 DSH executor-only provider guard、provider registry、anti-corruption adapter、vendor patch 登记、P2 审计记录和公共泄漏防护。
- `P3.sh`：检查 Hermes planner-only provider registry、原生 gateway/tool/loop/memory guard、vendor patch 登记、P3-01 审计记录和公共泄漏防护。
- `P4.sh`：检查 OpenClaw gateway-only provider registry、channel anti-corruption adapter、continue/redo/cancel command mapping、approved channel routing、集中防绕过、Plugin Bridge 白名单与 ClawHub/npm inventory、vendor guard、P4-01/P4-02/P4-03/P4-04 审计记录、dev/prod 端口隔离和公共泄漏防护。
- `P5.sh`：检查 P5-01 平台 REST API、P5-02 Web 控制台、P5-03 渠道接入管理、P5-04 TypeScript SDK 和开发者文档站、P5 阶段门禁报告、OpenAPI runtime alignment、管理员插件治理投影、P5-01/P5-02/P5-03/P5-04 审计记录、产品 API/控制台/渠道管理/SDK/docs 上游术语泄漏防护、P5 targeted contract/integration/security tests、SDK/docs examples 和 Vite build。
- `P6.sh`：检查 P6-01 deterministic in-process business closed loop、P6-02 anti-corruption attack matrix、tenant/data-spine authorization、双格式覆盖恶意插件隔离、P6-03 P6 fault injection matrix、Hermes disabled seeded platform plan lightweight route、provider 回滚、plugin rollback、真实 Docker Compose dev service lifecycle drill、P6 阶段门禁报告、TaskState/Coordinator 默认路线、OQ-PLUGIN-001/OQ-INFRA-006/OQ-PRODUCT-001 同步、P7 高级能力延后、P6-01/P6-02/P6-03 审计记录、`policy.denied`/`api.request.denied` 证据、Date.now 禁用扫描和 targeted E2E/security/fault tests；真实业务评测集、生产 durable workflow 和生产 sidecar/OS 隔离继续由 P8 扩展。
- `P7.sh`：检查 P7-01 默认关闭的内部 Observability 计划质量信号、`ExecutionPlan` deterministic static scoring、P7-02 默认启用 Conservative retention、Soft delete、Manual sweep、管理员 API+Console 操作、P7-03 技能自动评测 Default Off、Approved + Rejected deterministic corpus、API/SDK/Console Evaluations 管理面、P7-04 Default On Token 预算、All configured tenant/user/agent/task ledger、Task+adapter+API enforcement、Admin resolve queue 记忆冲突处理、P7-05 Default Off + manual tick 定时长期目标任务、UTC 5-field Cron-like recurrence、ordinary scheduler-source TaskRequest、API/SDK/Console Scheduled Goals 管理面、P7 阶段门禁报告、`OQ-PRODUCT-001`/`OQ-MEMORY-001`/`OQ-PLUGIN-001`/`OQ-BUDGET-001` 同步、P7-01/P7-02/P7-03/P7-04/P7-05 审计记录、公共面泄漏防护、Date.now 禁用扫描和 targeted unit/integration/security/evaluation/contract tests。
- `P8.sh`：检查 P8-01 生产 Compose/Kubernetes 编排、`config/services.prod.yaml` 生产服务清单、Kubernetes namespace/service account/config/secret template/deployments/services/ingress/network policies、仅 `platform-api` 与 `web-console` 暴露入口、内部 adapters 和数据服务无 public ports、无热更新/调试端口/source bind mount、`OQ-DEPLOY-001` 已关闭、P8-01/P8-02/P8-03 审计记录、P8-02 release gate、GHCR tag candidate publish、真实 runtime image scope、provider/plugin compatibility matrix、canary-first promotion、release pause、上游 optional remote check、P8-03 `nexus.observability_readiness.p8.v1` 告警目录、`nexus.backup_restore.p8.v1` backup/restore profile、RPO `15m`、RTO `4h`、NATS JetStream、S3-compatible Object Store、Vault、PostgreSQL + pgvector、OpenTelemetry + Prometheus/Loki/Tempo、metadata-only restore drill、audit hash-chain、Event Bus replay/DLQ、artifact checksum、memory version continuity、credential reference-only recovery、Date.now 禁用、secret/build artifact 扫描和 deployment/security targeted tests；法务发布包、真实客户 rollout 和完整 sidecar/OS 隔离继续由 P8-04 或后续治理承接。
