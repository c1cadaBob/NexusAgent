# 开发端口规划

开发阶段从 3050 开始连续分配宿主机端口，调试端口从 9250 开始连续分配。服务容器必须挂载源码并开启热更新；生产编排不得复用这些调试配置。

| 服务 | 宿主机端口 | 容器端口 | 用途 | 是否对外 | 调试端口 |
|---|---:|---:|---|---|---:|
| 平台统一 API | 3050 | 8080 | REST/gRPC 平台 API | 是 | 9250 |
| Web 管理控制台 | 3051 | 3000 | 管理界面 | 是 | 9251 |
| OpenClaw 网关适配器 | 3052 | 8080 | 渠道接入 | 否 | 9252 |
| DSH 执行器适配器 | 3053 | 8080 | 内部执行沙箱 | 否 | 9253 |
| Hermes 规划器适配器 | 3054 | 8080 | 内部规划记忆 | 否 | 9254 |
| Memory Gateway | 3055 | 8080 | 统一记忆代理 | 否 | 9255 |
| Artifact Store | 3056 | 8080 | 资产保存与引用 | 否 | 9256 |
| Event Bus | 3057 | 8080 | 内部事件分发 | 否 | 9257 |
| Credential Center | 3058 | 8080 | 凭据引用与权限控制 | 否 | 9258 |
| Observability | 3059 | 9090 | 指标、健康检查、告警 | 否 | 9259 |

端口变更必须同时更新 `config/ports.dev.yaml`、本文件、开发 Compose 和对应阶段冒烟脚本。P0 阶段的 Compose 仍为空服务占位，P1 才填入可运行服务。
