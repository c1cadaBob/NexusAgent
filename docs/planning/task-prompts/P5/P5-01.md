- 关键改动点：实现无新增 npm 依赖的 `createPlatformApi()`/Node `http` server，覆盖 health、tasks submit/list/get/cancel/retry/events、skills、capabilities、memory write/search、tenants/users/permissions、approvals/decision、budget check 和 admin plugin inventory/import/admission；所有受保护接口使用固定 dev bearer principal resolver，生产 IdP/SSO 延后；列表接口按 OpenAPI `limit/cursor` 返回 `next_cursor`；响应统一经 `assertPublicResponsePayload()` 投影，错误经平台错误码和 sanitizer 输出。
- 关键改动点：新增 `platform/plugin-governance/` 平台中性治理模块，聚合既有 Plugin Bridge 发现结果并只返回 capability name/type、risk、required_permissions、status、license/hash/NOTICE 元数据；import/admission 只做元数据登记和 allowlist 状态流转，不拉取包、不访问网络、不运行插件。
- 关键改动点：新增 `platform/public-surface/` 请求/响应 denylist，拒绝 raw credential、native URL/path/session/error、provider task/cancel、native agent/tool/memory、plugin subagent、manifest 绕过和上游品牌标记；`product/api/` 不 import 含上游名的 adapter 路径，公共 OpenAPI 不暴露上游品牌或 native 字段。

- 遇到的问题与决策：OpenAPI 已声明 cursor pagination，但初版 runtime 只返回数组；已补 `limit/cursor` runtime helper、tenant users OpenAPI 参数和 targeted tests，避免 `OQ-API-002` 只停留在文档层。
- 与计划偏离：未实现 gRPC/protobuf、SSE/WebSocket streaming、真实生产 IdP/SSO、SDK 生成、durable persistence、真实插件包导入或运行时恶意插件沙箱；这些均为计划内延期项，继续交给 P5-02/P5-04/P6/P8。
- 新增测试：`tests/contract/p5-openapi-contract.test.mjs` 覆盖 REST route、ID pattern、task state enum、cursor pagination、插件治理公共字段和 OpenAPI 泄漏；`tests/integration/platform-api-rest.test.mjs` 覆盖 health、task lifecycle、cursor pagination、memory、approvals、budget、tenants/users/permissions、plugin governance；`tests/security/platform-api-leakage.test.mjs` 覆盖 auth fail closed、跨租户、blocked payload、invalid pagination、event/inventory 投影和 product API source 泄漏扫描；`tests/security/plugin-governance-api.test.mjs` 覆盖平台管理员权限、URL/path/credential/manifest 绕过拒绝和 admission 状态流转；`tests/smoke/P5.sh` 串联 required files、审计记录、OpenAPI/runtime markers、公共面泄漏、Date.now 检查和 targeted P5 tests。
