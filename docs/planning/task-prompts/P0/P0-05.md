1. `git status --short --branch`
2. `git diff --check -- . ':!vendor/**'`
3. `bash tests/smoke/P0.sh`（若该阶段脚本尚未存在，本任务涉及该阶段脚本时必须创建；否则在报告中标记为【待确认问题】并说明替代验证命令）
