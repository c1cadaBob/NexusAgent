# 任务实施规划提示词索引

> 本目录由 `scripts/planning/generate-task-prompts.py` 生成。每个任务 ID 对应一份完整可复制的实施规划提示词。
>
> 注意：各任务文档的“角色设定”已按任务目标和实现节点人工优化。后续如重新生成本目录，必须逐个复核角色定位、工作重点和禁止事项，禁止回退为同一套通用角色描述。

## 实时规划提示词规则

- 开始实现任务前，必须先填写对应任务文档的“修改前分析”。
- 如果“修改前分析”发现存在 `打开`、缺少确认文件、或已 `自动确认` 但尚未同步修复的 `OQ-*`，必须先处理待确认问题，再进入下一步实现。
- 修改过程中持续补充“修改过程记录”；完成验证后补齐“修改后验证与总结”。
- 如果任务结束时仍有未处理待确认问题，必须在确认后根据当前阶段进度排到后续任务，并在本目录对应阶段文件夹创建或更新实时规划提示词。
- 已 `自动确认` 但尚未同步到任务文档、风险、追踪矩阵或专业文档的问题，必须创建同步修复类实时规划提示词。
- 每个阶段结束前，必须回扫当前阶段及其之前阶段的任务文档和 `OQ-*`，确认是否还有未处理、未同步或需要修复的问题；没有明确后续实时规划提示词、责任人和截止阶段时，不得进入下一阶段。
